# Translation model attribution

This project downloads the Argos Translate package `translate-en_pt-1_9` from:

<https://argos-net.com/v1/translate-en_pt-1_9.argosmodel>

The package identifies the translation model as OPUS-MT English-to-Portuguese,
version 1.9, by Jörg Tiedemann and Santhosh Thottingal. The OPUS model is
licensed under Creative Commons Attribution 4.0 International (CC BY 4.0):

<https://creativecommons.org/licenses/by/4.0/>

The model package is not stored in this source repository. The preparation
script downloads the pinned package and verifies its SHA-256 checksum before
installation.
